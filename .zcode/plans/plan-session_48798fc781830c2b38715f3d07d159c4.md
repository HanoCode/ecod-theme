# 侧栏「实时动态」挂件 —— 原地升级 ticker 为多源滚动动态流

截图样式：头像 + 名字·相对时间 + 动作文案（“触发「打卡奖励事件」，获得 Credit +10”）的纵向无缝滚动流。经确认：**原地升级现有 `ticker` 挂件**（保留挂件 ID 与已存实例，模板/CSS 换新），**默认纯服务端渲染不轮询**，后台参数可选开轮询。

## 1. 数据聚合层 —— `core/site/activity.php`（新文件）

`ecod_activity_feed(array $sources, int $limit): array`：多源采集 → 统一条目 `{kind, uid, name, avatar, text, delta, href, created}` → 按时间倒序合并截断。五个来源采集器：

| 来源 key | 数据 | 文案（第二行） | 链接 |
|---|---|---|---|
| `credit` 积分 | `ecod_credits_public_rows()`（已有，排除 admin 调账） | `每日签到，获得 Credit` + `<b>+10</b>` | 作者主页 |
| `task` 任务 | `ecod_task_claims` 表倒序，任务名走 `ecod_tasks_map()` | `完成「首次评论」，获得 Credit` + delta | 作者主页 |
| `comment` 评论 | comments 表（type=comment, status=approved），两步查 contents 标题 | `评论了「文章标题」` | 文章 permalink + `#comment-{coid}` |
| `post` 文章 | contents（publish/post），authorId 两步查用户名 | `发布了新文章「标题」` | 文章 permalink |
| `user` 成员 | users 表 ORDER BY created DESC（默认不勾选） | `加入了站点` | 作者主页 |

- 头像回退链（仿 meta.php:140）：uid → `ecod_account_avatar_url()` → `ecod_local_avatar_url('uid:'.$uid)`；访客评论 → `ecod_comment_avatar_url($mail)`。
- permalink 用 `Router::url` + 复用 `ecod_sitemap_link()`（seo.php:1049）；api.php 场景先 `Router::setRoutes(Options::alloc()->routingTable)`（仿 seo.php:728）。
- 隐私门槛：credit/task 来源需 `ecod_credits_enabled()` 且 `ECrTicker=on`（沿用现有播报隐私开关口径），不满足时该来源静默跳过。
- 缓存：`ecod_cache_remember('ticker_'.md5(sources.limit), 60, fn)`（core/lib/cache.php）。

## 2. 挂件定义 —— `core/admin/blocks-def.php` 原地升级 `ticker`

name 改「实时动态」，desc 更新。params 增加：
- `sources`：**`checks` 多选字段（新增字段类型）**，选项 comment/credit/task/post/user，默认 `comment,credit,task,post`，存逗号串；
- `visible`：number 2–6 默认 3（视口可见条数，决定 viewport 高度）；
- `refresh`：select 不刷新/60s/180s/300s，默认不刷新；
- 保留 `limit`（3–15）/`seconds`（10–120）。

## 3. 后台字段渲染 —— `assets/admin/widget.js`

`fieldEl()` 新增 `checks` 类型分支（仿现有 `terms` 多选勾选列表，选项来自 `param.options` 而非 DATA.terms，存储逗号分隔串）。

## 4. 参数清洗 —— `core/admin/widget-clean.php`

`ecod_wgt_clean_params()` 增加 `case 'checks'`：按声明 options 的 key 白名单过滤后逗号拼接。

## 5. 前台模板 —— `components/aside/ticker.php`（重写）

- 门槛→`ecod_block_setup_hint()`：勾选了 credit/task 但积分未开/播报关 → 指路卡；来源全空/无数据 → 访客零输出、管理员提示卡。
- 结构沿用：`.ecod_widget.ecod_ticker` 根 + LIVE 呼吸徽标 + viewport（inline 高度 = visible×58px，上下渐隐 mask）+ 列表渲染两份实现无缝滚动（纯 CSS，`animation-duration` inline）。
- 条目新标记：`<a class="ecod_act__item">` = 头像（32px，`--ecod-avatar-radius`）+ 主列（`名字 · 3小时前` / `文案 + <b>+10</b>`）。
- 根元素挂 `data-ecod-ticker` + `data-api` + `data-refresh` + `data-sources` + `data-limit`，供轮询 JS 使用。

## 6. CSS —— `assets/css/ecod.css` §37

替换旧 `.ecod_ticker__item` 单行样式为双行头像条目样式（类前缀 `ecod_act__`），复用现有 viewport/keyframes/hover 暂停；全部走 token（自动深浅色），hover 规则包 `@media (hover: hover)`，头像 img 补暗色描边（仿 ecod.css:4309）。§37 已在 core 族，无需改 build.mjs。

## 7. 轮询 JS —— `assets/js/ecod.global.js`

新增 `Ecod.initTicker`：仅当 `data-refresh` 开启时按秒数轮询 `api.php?action=ticker`；数据有变（JSON 比对）时在 `animationiteration` 滚动一圈边界无缝重建两份列表（不跳帧；动画被 reduced-motion 关闭则立即重建），并用同款相对时间函数渲染。挂入 `Ecod.refresh()` 调用清单（幂等守卫 `dataset.tickerReady`）。

## 8. API —— `api.php`

新增公开只读 GET `action=ticker`（仿 `search_suggest` 端点写法）：sources 白名单校验 + limit 钳制 + 60s 缓存，头部补 `require core/site/activity.php`。nginx 白名单无需动（api.php 是既有入口）。

## 9. 构建与验证

- `php -l` 全部改动 PHP 文件；
- `cd build && npm run build`（CSS 分族/关键 CSS/压缩产物 + manifest 一并更新并提交）；
- 本地站点 curl 验证：`api.php?action=ticker` 返回结构、含挂件页面的 HTML 渲染（ticker 实例需在后台启用，或临时直查模板函数输出）。
