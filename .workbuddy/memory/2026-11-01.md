## 文章卡片短代码支持显示类型（[posts] / [article]）

- **改法**：`[posts mode=…]` 与新增的 `[article mode=…]` 直接吃后台「版式 → 默认卡片模式」（ECardMode）那 10 种取值；留空跟随后台默认，旧写法 `mode=list` 等价 `default`。渲染改走 `ecod_card()` + `ecod_list_class()`，与首页/分类列表同一套卡片（原 `.ecod_posts` 紧凑样式与 `ecod_sc_posts_rows()`、`ecod_sc_thumb_fields()` 一并删除）。
- **查询**：新增 `ecod_sc_card_query()` 用 `\EcodPostQuery::allocWithAlias('sc'.n)` 取独立实例——Widget 池按别名缓存，共用别名第二次调用会拿到已走完的堆栈（第二段列表空白）。排序词映射：date→recent / hot→views / comment→hot / random→rand；`EcodPostQuery` 的 `exclude` 扩展为支持逗号多值。
- **递归坑（关键）**：`ecod_card()` 取摘要会读 `$archive->content` → 触发 contentEx → 短代码过滤器 → 正文里的 `[posts]` 再展开 → 无限递归 128M OOM。`ecod_sc_card_render()` 渲染期间挂 `$GLOBALS['ecodScRendering']`，`ecod_shortcode_apply()` 见标志只跑表情替换直接返回。
- **正文样式污染**：卡片落在 `.ecod_content` 里会被 `.ecod_content a/h3/p/img`（0,1,1 > 卡片 0,1,0）顶成正文样式。容器加 `ecod_sc_cards`，在 §23 末尾逐条还位（标题字号/颜色、去下划线、清零 p/img 外边距）。还有一处：`.ecod_content img` 让 note 卡的作者头像块级化把作者名挤成 0 宽（ellipsis 吃掉），需 `display:inline-block + width/height auto + max-width:none`，并给 `.ecod_card__meta-author / __likes` 加 `flex:none`。
- **CSS 族**：§50 笔记卡样式在 list 族，`ecod_css_family()` 在 post/page 正文含 `[posts]`/`[article]` 时追加 `list`；`ecod_postext_needed()` 正则补 `posts`（`ecod_posts__head` 在 §23/postext）。
