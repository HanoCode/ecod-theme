## 导航下拉图标卡片 hover 修正（§03.5 `.has-icons`）
- 根因：图标块 hover 用了 `--ecod-primary-btn`——它是为「大按钮+白字」压 WCAG 对比度设计的派生色（琥珀下混黑到 #a26807），压到 34px 图标块上成「深棕底+近黑字」，闷且脏；行 hover 底 `--ecod-surface-2`(#fafbfc 冷白) 与暖琥珀主题冷暖冲突；hover 文字 `--ecod-primary`(#f59e0b) 白底仅 2.17:1 发虚。
- 修法：行底改 `color-mix(soft 62%, surface)` 暖白茶（附 soft 兜底）；**基础文字色 `--ecod-text`(#12161d 近黑) → `--ecod-text-2`(#5b6472)**（原来图标网格项比普通下拉更黑）；文字 hover 用 **`--ecod-primary-deep`(#ce8509) 浅色 / `--ecod-primary` 暗色**；**图标块不反相**——反相（`primary` 底 + `primary-ink` 字）要让文字达标就得用深墨 #12161d，压在亮橙块上就是"黑字"，用户连否两次；改为保持浅底 + 主色图形，加 `inset box-shadow` 主色 40% 描边 + scale 1.04。
- **经验**：`--ecod-primary-ink` 在亮色块上必然呈现"黑字"观感；只有「大块填充 + 白字按钮」场景用它才成立，小图标块慎用。
