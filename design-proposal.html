01 · 设计策略

DOM 不动，CSS 重生

模板骨架、节点层级、包裹关系与 Joe_2 完全一致（便于后续合并上游修复）；仅替换类名/ID 前缀与样式实现，CSS 零继承、全部重写。

① DOM：1:1 保持

保留 #Ecod > .ecod_container > .ecod_main / .ecod_aside 三层骨架；public/header|aside|footer 的嵌套顺序、.ecod_card 的四种模式分支都不变。好处：模板渲染逻辑、AJAX 输出、上游更新均可平移。

② 命名：统一前缀替换

结构不变但标识换成主题命名：joe_header → ecod_header，#Joe → #Ecod。JSON 接口字段、Cookie 名同样改前缀，与 Joe 彻底隔离，避免同站共存冲突。

③ CSS：零继承重写

不引用任何 joe.*.css。以 tokens + 组件分层重写：base（reset/变量）→ layout → components → pages，输出单一入口 ecod.css。

03.5 · 后台

导航菜单管理器

参考 WordPress「外观 → 菜单」的心智：左边挑项加入，右边拖拽排序、缩进成二级。支持一级 + 二级两层；某个一级下的二级项超过 6 个时，下拉面板自动分两列。全部菜单存成一个 option（ENavSets 的 JSON），前台 header 与移动抽屉共用同一套配置，改一次两处同步。站点可保存多套导航，后台顶部一个下拉随时切换，选择的那套即刻成为前台生效的导航。

字段类型说明
typepage / cat / tag / link / home页面与分类/标签存 slug 或 mid，改名换地址自动跟随；home 固定指向站点根

attrstring链接的 title 属性（悬停提示），可留空；输出时转义
clsstring附加到 <a> 的 CSS 类，仅保留 [A-Za-z0-9_-] 片段、最多 5 个；用于单条菜单的特殊样式
childrenarray仅一级项可有；元素字段同上但不再嵌套，超出部分渲染时忽略
规则
回退ENavMenu 为空（或从未配置）时，前台沿用旧逻辑：全部独立页面（ENavHide 排除）+ ENavLinks 文本链接。老站升级零感知
层级上限两层。第三个层级在后台不被允许（缩进按钮在同一父项下再点无效），渲染侧对多余嵌套直接拍平
分栏某个一级的二级项 > 6 时下拉面板加 is-cols，网格两列（每列 ≥160px）；≤6 保持单列
溢出ENavMax 仍生效：超出的一级项收进「更多」下拉，二级按同样规则渲染在其下。另有 JS 兜底（Ecod.initNavOverflow）：视口放不下时把尾部整条 li（连同二级）收进「更多」，变宽自动还原；搬运单位必须是整个 li，只搬 <a> 会把二级丢掉（2026-10-29 事故：二级菜单在前台被此逻辑清除）。下拉内的二级改渲染为静态缩进列表，不再是悬浮面板
指示箭头chevron 素材默认朝右，导航场景统一转 90° 使用：收起朝下、展开朝上（.ecod_nav__caret / 「更多」summary / 抽屉 .ecod_drawer__group 三处同规则；展开态 270°，带 --ecod-dur-fast 翻转过渡）。面包屑、章节头「全部」等横向指示保持素材原方向朝右
高亮页面按 is('page', slug) 命中；分类/标签按 is('category', slug) / is('tag', slug)；首页按 is('index')；命中二级时父项同时加 is-active
PJAX高亮地址随 shell 的 data-ecod-nav-active 输出，换页后 JS 按该值同步；下拉菜单本身无状态，不需要重新初始化
存储单个隐藏字段 ENavSets（JSON，含多套菜单与 active），随主题设置一起保存；导出 / 导入 / 快照自动覆盖，无需额外处理
多套导航

同一份数据里存多套菜单，后台顶部一个切换条；下拉选中的那套既是前台生效的导航，也是右侧正在编辑的对象。切换不清空数据，保存设置后前台按新选择渲染。

后台 · 导航切换条（.ecod-navb__bar）
当前导航 主导航 ⌄ ＋ 新建 复制 重命名 删除 切换后点「保存设置」生效
字段类型说明
sets[].idstring稳定标识（s + base36 时间戳），重命名不改 id
sets[].namestring后台展示名，仅用于识别，最长 24 字
sets[].notestring备注，只在后台显示（如「活动期用」），最长 60 字，不参与前台渲染
sets[].itemsarray菜单树，项字段见上表
activestring前台生效的套 id；为空或指向已不存在的 id 时回退到第一套
切换下拉选项即「前台生效的导航」，同时是右侧正在编辑的那套。切换保留各套未保存的改动，随「保存设置」一次性提交
新建 / 复制新建走页内弹窗（.ecod-navb-modal，遮罩 + 对话框，非原生 prompt/alert）：标题「新建导航」+ 名称输入（默认「导航 N」），取消 / 创建；Enter 提交、Esc 与点击遮罩取消。复制深拷贝当前套全部项并命名「XX 副本」。最多 10 套，超出用同款弹窗提示先删
重命名 / 删除重命名只改 name，不动 id 与项；删除后 active 落到剩余第一套，删掉最后一套时前台回到自动导航
迁移升级前只有 ENavMenu 的老数据，首次加载时在内存里提升为「默认导航」一套；一旦存过 ENavSets 就不再读旧字段
上限单套项数沿用构建器规则；套数 10、单套一级 40 项、单套二级各 24 项，超出部分渲染时截断

取：模块化编排

RiPro 的首页本质是「可排序的模块数组」。Ecod 用同一思路：每个模块独立模板，后台拖动排序、逐个开关。

取：信息密度

苏醒的卡片在标题下就给出分类、时间、互动数，扫读效率高。Ecod 卡片统一一行元信息，不堆砌。

舍：商城化

不做价格、积分、订单、付费下载。保持纯内容站，减少后台配置项与安全面。

29 · 后台交互

设置项的条件联动

设置项之间存在真实的生效依赖：总开关没开，子项填了也不生效。后台按「只看当下一步要填什么」组织：条件不满足的字段直接隐藏，控制字段下方给出隐藏数量提示，整组失效时在分组顶部给出提示条。

三段式呈现

① 字段级隐藏

子项条件不满足时整行移除出视野，不留占位、不置灰。父项被隐藏时，其下级字段一并隐藏（链式求值，最多 4 轮收敛）。

② 父项计数提示

控制字段下方追加一行浅色小字：另有 3 项关联设置已隐藏（开启后显示）。用户知道关掉它顺手关了什么，也知道打开后会出现新内容。

③ 分组级提示条

整组设置因外部开关失效时（如全站评论关闭、侧栏设为「无侧栏」），分组顶部出现提示条，附「去开启」按钮，一键跳回控制该组的字段并高亮。

条件表达式

挂在控件上的 data-ecod-show-when，挂在分组面板上的 data-ecod-pane-when，同一套语法。

写法含义
ECommentProvider:twikoo控制字段等于该值
ECommentProvider:twikoo|waline等于其中任一值
ECardMode:!=bare|title不等于其中任一值（前置 !）
ELogoImage:!empty该字段非空（empty 为判空）
ECode:on,EFloatToc:on逗号分隔为「且」，全部满足才显示
降级JS 未加载时所有字段照常显示并可保存，联动只是可见性增强，不影响任何取值与提交。

块参数抽屉

块参数在 core/blocks-def.php 用 when 声明，抽屉内实时重算，不需要关闭重开。

'slides' => [ 'type' => 'slides', ... ],
'count'  => [ 'label' => '轮播数量', 'type' => 'number', 'when' => 'slides:empty' ],
'source' => [ 'label' => '文章来源', 'type' => 'select', 'when' => 'slides:empty' ],

已接入：轮播的「数量 / 来源」随自定义幻灯片是否为空显隐；互动按钮的「支付宝 / 微信收款码」随赞赏开关显隐。
