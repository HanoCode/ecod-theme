# Ecod Theme

一个偏「阅读 + 轻社交」的 Typecho 主题：卡片列表、首页模块化布局、深浅色、PJAX 无刷新跳转，
正文侧带短代码、代码高亮、相关阅读、阅读时长与过期提醒，评论区带等级徽章与表情面板。
不依赖任何前端框架与 CDN，所有样式与脚本都随主题打包。

---

## 一、环境要求

| 项目 | 要求 |
| --- | --- |
| Typecho | 1.3.0 及以上（1.2 未测试，不保证可用） |
| PHP | 8.0 及以上（推荐 8.1+） |
| 数据库 | MySQL 5.7+ / MariaDB 10.2+（SQLite 未适配） |
| 浏览器 | 支持 CSS 变量、`aspect-ratio`、`<details>` 的现代浏览器 |

主题会在首次访问时自动补齐自己需要的表与字段，不需要手动执行 SQL：

- `{prefix}ecod_likes`：点赞记录（`cid` + 访客指纹唯一索引）
- `{prefix}contents.views`：阅读量计数列

---

## 二、安装与启用

1. 把 `ecod-theme` 整个目录放进 `usr/themes/`；
2. 后台「控制台 → 外观」启用 **Ecod**；
3. 进入「外观 → 设置」，左侧是分组导航，改完点右上角 **保存设置**。

> 首次启用后建议先到「工具」页点 **保存快照**，改坏了可以一键回滚。

**侧栏（13 个）**

`关于本站` `作者卡片` `文章目录` `最新文章` `最新评论` `标签云`（流式胶囊，带文章数与字号梯度）`热门文章` `排行榜` `分类目录` `按月归档` `搜索框` `站点统计` `侧栏广告位`

| --- | --- |
| 评论服务 | 原生（Typecho）/ Twikoo / Waline / Artalk / Giscus。选第三方后原生列表与表单不再输出，由外部服务整块接管 |
| 第三方地址 | Twikoo 填 envId 或自建地址；Waline / Artalk 填服务地址；Giscus 需仓库、Repo ID、分类与分类 ID（都可在 giscus.app 配置页复制） |

## 五、短代码

正文里直接写短代码即可，共 **37 个标签 + 31 个表情**。编辑器侧边栏「短代码」菜单可一键插入，工具栏表情按钮可点选表情，右侧预览实时渲染。

完整语法、属性与示例见 **[docs/shortcodes.md](docs/shortcodes.md)**，速查：

| 分组 | 标签 |
| --- | --- |
| 提示与强调 | `note` `alert` `message` `callout` `anote` |
| 排版元素 | `mtitle` `copy` `progress` `abtn` `dotted` `lamp` `task` `mark` `kbd` `tooltip` `badge` `spoiler` |
| 折叠 / 选项卡 / 时间线 | `fold` `tabs`+`tab` `timeline` |
| 卡片与网格 | `cards` `grid` `card` |
| 下载与网盘 | `download` `cloud`（自动识别 15 种网盘） |
| 内容引用与可见性 | `posts` `article` `github` `reply` `hide`（登录 / 评论 / 等级 / 密码） |
| 媒体 | `gallery`（相册 / 瀑布流 + 灯箱） `bilibili` `video` `mp3` `music` |
| 表情 | `:smile:` `:cry:` `:beer:` 等 31 个 |

三个最常用的例子：

```
[note type="tip" title="提示"]这是一条提示[/note]

[download url="https://pan.baidu.com/s/1abc" name="完整包" size="12.4 MB"]提取码见内[/download]

[reply]这段内容只有留下过评论的访客能看到。[/reply]

[posts related="1" limit="4" title="延伸阅读"]
```

> 短代码不会作用于 `<pre>` / `<code>` 内部，代码示例里可以放心写方括号。

## 七、SEO

主题在 `<head>` 输出并自动去重：

- `<title>` / `canonical` / `description`（自动去 `utm_*`、`ecod_*` 查询参数）
- Open Graph + Twitter Card（Typecho 自身输出 `og:type` 时自动跳过，不重复）
- JSON-LD `@graph`：`WebSite` + `SearchAction`、`Article`、`BreadcrumbList`、`WebPage`

`/feed` 由 Typecho 原生输出。

**sitemap.xml 与 robots.txt**：如果站点没开伪静态，`/sitemap.xml` 请求根本到不了 PHP，请到「工具」页点 **生成文件**，会在站点根目录写出静态文件；之后每次发完新文章回来点一次即可（生成接口需要管理员登录 + 一次性令牌，不会被外部调用）。

## 九、常见问题

**Q：点了「生成文件」但浏览器里 `/sitemap.xml` 还是 404？**
A：确认文件写到了站点根目录（`__TYPECHO_ROOT_DIR__`）。若用容器部署，注意目录挂载权限。

**Q：搜索两个词（如「测试 卡片」）结果不对？**
A：Typecho 核心会把搜索词按 slug 规则规范化，空格在进入主题前就丢了，所有主题都一样。本主题的适配是：无空格时按字母段与中文段切分，并对长中文串补 2-gram 建议，空结果页给出「按词查找」词条。

**Q：代码块没有颜色？**
A：高亮是前端分词，语言取自 `<pre><code class="language-xxx">`。没有语言类名时会按内容启发式猜一次；猜不出来就保持单色。后台「代码高亮」开启时由 Prism 统一染色（语言缺省也能上色），关闭时回落到内置高亮器。

**Q：评论区的等级徽章怎么算的？**
A：按同一邮箱的已审核评论条数，阈值 1 / 5 / 10 / 20 / 40 / 80 / 160，对应「初见 / 常来 / 熟客 / 老友 / 资深 / 元老 / 镇站」。

**Q：评论没有嵌套 / 只能嵌套很浅？**
A：两处设置共同决定。①后台「设置 → 讨论」要勾选「启用嵌套评论」，最大嵌套层数默认 5；②主题「评论 → 嵌套折叠深度」控制前几层直接展开，超过的部分收进「展开 N 条回复」；③「评论 → 长讨论的展开方式」决定这些折叠是逐条点开、用一个顶部总按钮一次铺开，还是干脆不折叠。评论总数按全部已审核评论统计（含回复），不再只数顶层。

**Q：改了配置想回滚？**
A：工具页的快照列表，点「恢复」。恢复前会自动给当前状态存一份，所以误点也能回去。

**Q：主题升级会不会覆盖我的设置？**
A：设置存在 `options` 表的 `theme:ecod-theme` 里，跟主题文件分离。升级前建议先导出一份 JSON。

## 十、服务器加固

主题内的 PHP 只需要 4 个入口能被浏览器直接访问：`api.php`、`media.php`、`pay-admin.php`、`manifest.php`，其余一律 403（Apache 由主题目录的 `.htaccess` 处理）。**nginx 不读 .htaccess**，请在 server 块里加等效配置：

```nginx
# 主题目录：只放行 4 个独立入口，其余 PHP 直连拒绝
location ~* ^/usr/themes/ecod-theme/(?!api\.php$|media\.php$|pay-admin\.php$|manifest\.php$).+\.php$ {
    deny all;
}
```

再按需叠加（均建议配置在站点层）：

```nginx
# HSTS（全站 HTTPS 且确认不再回退 http 后再开）
add_header Strict-Transport-Security "max-age=31536000" always;

# 上传目录禁止执行任何 PHP（优先级最高的加固之一）
location ~* ^/usr/uploads/.+\.php$ { deny all; }
```

主题自身已在 `public/header.php` 输出 `X-Content-Type-Options` / `X-Frame-Options` / `Referrer-Policy` / `Permissions-Policy`；CSP 建议先用 `Content-Security-Policy-Report-Only` 观察、收集到违反报告后再收紧为正式策略。
