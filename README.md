# Ecod Theme

一个偏「阅读 + 轻社交」的 Typecho 主题：卡片列表、首页模块化布局、深浅色、PJAX 无刷新跳转，
正文侧带短代码、代码高亮、相关阅读、阅读时长与过期提醒，评论区带等级徽章与表情面板。
不依赖任何前端框架与 CDN，所有样式与脚本都随主题打包。

---

## 一、环境要求

| 项目 | 要求 |
| --- | --- |
| Typecho | 1.3.0 及以上（1.2 未测试，不保证可用） |
| PHP | 8.0 及以上（推荐 8.1+） |
| 数据库 | MySQL 5.7+ / MariaDB 10.2+（SQLite 未适配） |
| 浏览器 | 支持 CSS 变量、`aspect-ratio`、`<details>` 的现代浏览器 |

主题会在首次访问时自动补齐自己需要的表与字段，不需要手动执行 SQL：

- `{prefix}ecod_likes`：文章点赞记录（`cid` + 访客指纹唯一索引）
- `{prefix}ecod_clikes`：评论点赞记录（结构同上，`coid` 维度）
- `{prefix}ecod_follows`：关注关系（`uid` + `target` 唯一，仅登录用户）
- `{prefix}ecod_user_meta`：用户扩展资料（一句话简介等，`uid` + 字段名唯一）
- `{prefix}contents.views`：阅读量计数列

---

## 二、安装与启用

1. 把 `ecod-theme` 整个目录放进 `usr/themes/`；
2. 后台「控制台 → 外观」启用 **Ecod**；
3. 进入「外观 → 设置」，左侧是分组导航，改完点右上角 **保存设置**。

> 首次启用后建议先到「工具」页点 **保存快照**，改坏了可以一键回滚。

**首页（15 个）**

`搜索盒` `分类导航` `轮播` `推荐位` `热门四宫格` `动态流` `焦点双栏` `分类精选` `标题速览` `数据概览` `合集` `快讯` `合作伙伴`（Logo 墙）`广告位` `正文流`

**侧栏（14 个）**

`关于本站` `作者卡片` `文章目录` `最新文章` `最新评论` `标签云`（流式胶囊，带文章数与字号梯度）`热门 Tab 组`（热门 / 热评 / 最新 / 随机四合一选项卡）`热门文章` `排行榜` `分类目录` `按月归档` `搜索框` `站点统计` `侧栏广告位`

**文章页（6 个）**

`互动按钮`（点赞 / 收藏 / 复制链接 / 微信扫码 / 社交分享）`朗读条`（浏览器语音合成，可调语速）`版权声明`（作者 / 原文链接 / 转载协议）`文末作者卡`（头像 / 简介 / TA 的文章入口）`上下篇导航` `相关推荐`（同标签优先，同分类补齐，不足用最近文章兜底）

**页脚（5 个）**

`版权信息` `页脚链接` `回到顶部` `阅读进度` `深浅色切换`

### 4.6 评论

| 选项 | 说明 |
| --- | --- |
| 评论服务 | 原生（Typecho）/ Twikoo / Waline / Artalk / Giscus。选第三方后原生列表与表单不再输出，由外部服务整块接管 |
| 第三方地址 | Twikoo 填 envId 或自建地址；Waline / Artalk 填服务地址；Giscus 需仓库、Repo ID、分类与分类 ID（都可在 giscus.app 配置页复制） |
| 嵌套折叠深度 | 2–5 层。前 N 层始终展开，更深的回复收进「展开 N 条回复」，点开后再显示；实际层数上限仍由 Typecho「设置 → 讨论」的最大嵌套层数决定 |
| 长讨论的展开方式 | `逐条展开`（每条折叠各自有按钮）/ `顶部总按钮`（列表上方给一个「展开全部回复」，一次铺开所有折叠，再点变「收起全部回复」）/ `全部展开`（不折叠）。没有折叠节点时总按钮自动隐藏 |
| 人机验证 Turnstile | Cloudflare 免费方案，前端渲染挂件、服务端 `siteverify` 校验；只作用于原生评论 |
| 反垃圾 Akismet | 提交时送 Akismet 检测，判定为垃圾直接标记 spam（前台与后台默认列表都不显示）；接口异常时放行 |
| 头像 | 本地随机头像池（`assets/avatar/`）：按邮箱 / uid 确定性分配，同一人永远是同一张；登录用户可在个人中心上传自定义头像（带裁剪），不请求任何外部头像服务 |
| 评论表情 | 系统 Emoji（40 个字符表情）或图片表情包（主题内置 31 个，配合正文 `:smile:` 短代码） |
| 表情包 CDN 前缀 | 填了就从外部 CDN 取图，例如 `https://cdn.example.com/smiley/`；留空用主题本地 `assets/img/smiley/` |

> 第三方评论系统接管时，Turnstile 与 Akismet 不参与（评论不经过 Typecho），审核与反垃圾需在对应服务端配置。

### 4.7 投稿与社区

| 选项 | 说明 |
| --- | --- |
| 前端投稿 | 开启后，登录用户在「投稿」页提交文章，进入后台「待审核」列表，管理员点发布即上线。需先用「工具 → 特色页」创建投稿页并放入导航 |
| 投稿用户组下限 | 投稿者及以上（默认）/ 所有登录用户 |
| 可投稿分类 | 顶级分类 mid，逗号分隔；留空表示全部顶级分类 |
| 投稿须知 | 显示在投稿表单上方的说明文字 |
| 评论点赞 | 每条评论右下角的「赞」按钮：访客按浏览器指纹去重，登录用户跨设备同步；第三方评论接管时不显示 |
| 关注作者 | 作者主页头卡与文章页作者卡上的「关注」按钮；个人中心「我的关注」管理列表，粉丝数就地更新。私信暂未提供 |
| 版权模板 | 「设置 → 文章页 → 版权模板」按「名称丨声明文本」逐行定义；文章自定义字段 `copyright` 填名称即选用对应文本 |
| 网址导航数据 | 「网址导航」页的站点数据。空行分隔分组，每组第一行「组名丨组描述」，之后每行一个站点「名称丨链接丨描述」，第 4 段可选（图标地址） |

投稿的防刷与登录/友链申请同一套：同源校验 + CSRF 令牌 + 蜜罐 + 图形验证码 + 分级限流。
投稿人可在「个人中心 → 我的文章」里看待审核进度，待审核 / 草稿可回投稿页修改或撤回。

### 4.8 主题授权

商业授权版在「站长 → 主题授权」完成激活，面板提供状态卡、激活（输入授权码即可，域名自动识别当前站点）与离线导入；已授权时激活入口自动收起。

授权面板**不包含任何作者端配置**——授权模式默认开启（不可关闭，见下），校验端点内置，售价与换绑次数由作者站的 EcodLicenser 插件配置（「Ecod Licenser → 设置 → 商品定价」），买家主题里不出现这些字段。

| 项 | 说明 |
| --- | --- |
| 授权模式 | 默认开启且无开关：未激活（7 天试用后）/ 过期 / 域名不匹配 / 被吊销会锁定前台（503 + Retry-After），管理员登录后可关闭弹窗继续浏览。localhost / 内网 IP / `.local` `.test` 等本地环境自动豁免；作者站与自建分发站在 `config.inc.php` 里 `define('ECOD_LIC_DISABLED', true)` 关闭 |

- **激活**：输入授权码点「立即激活」即可，绑定域名自动识别为当前站点；授权文件由作者端签名，主题内置公钥验签，不依赖端点返回的公钥。激活成功后激活 / 导入入口自动收起。
- **离线导入**：内网 / 作者端不可达时，把 `ECODLIC1.…` 整串粘贴到「离线导入」，走同一套本地验签。
- **周期复验**：每次请求只读本地 option，零网络；每 7 天在后台异步复验一次。断网不立刻锁站：超过宽限天数后台提示，超过宽限 + 14 天才降级锁定。
- **试用期**：首次启用后 7 天内不锁站，方便先装修再激活。
- **模块授权**：授权文件里的 `modules` 可单独关闭 `pay` / `member` / `ads` / `card` / `shop`；旧授权文件没有该字段时视为全开。
- **自助购买（作者站会员中心）**：「个人中心 → 我的授权」选版本 → 填绑定域名（失焦即预校验占用）→ 下单支付，付款后立即出码，页内给出三步激活指引；支付回跳自动轮询出码。
- **换绑域名**：每张码累计 2 次（可按客户调整），换绑后旧站立即失效，需到新站后台重新激活；额度用完「更换域名」按钮置灰。
- **原地升级**：授权卡上「升级团队版」按差价下单，支付后同一张码重签升级，域名与换绑计数不变。

> 授权只防「一份授权多处部署」和「到期不续费」，不防有心破解（PHP 源码可见）。锁页对外文案保持中性，不出现「盗版 / 未授权」字样。

## 五、短代码

正文里直接写短代码即可，共 **37 个标签 + 31 个表情**。编辑器侧边栏「短代码」菜单可一键插入，工具栏表情按钮可点选表情，右侧预览实时渲染。

完整语法、属性与示例见 **[docs/shortcodes.md](docs/shortcodes.md)**，速查：

| 分组 | 标签 |
| --- | --- |
| 提示与强调 | `note` `alert` `message` `callout` `anote` |
| 排版元素 | `mtitle` `copy` `progress` `abtn` `dotted` `lamp` `task` `mark` `kbd` `tooltip` `badge` `spoiler` |
| 折叠 / 选项卡 / 时间线 | `fold` `tabs`+`tab` `timeline` |
| 卡片与网格 | `cards` `grid` `card` |
| 下载与网盘 | `download` `cloud`（自动识别 15 种网盘） |
| 内容引用与可见性 | `posts` `article` `github` `reply` `hide`（登录 / 评论 / 等级 / 密码） |
| 媒体 | `gallery`（相册 / 瀑布流 + 灯箱） `bilibili` `video` `mp3` `music` |
| 表情 | `:smile:` `:cry:` `:beer:` 等 31 个 |

三个最常用的例子：

```
[note type="tip" title="提示"]这是一条提示[/note]

[download url="https://pan.baidu.com/s/1abc" name="完整包" size="12.4 MB"]提取码见内[/download]

[reply]这段内容只有留下过评论的访客能看到。[/reply]

[posts related="1" limit="4" title="延伸阅读"]
```

> 短代码不会作用于 `<pre>` / `<code>` 内部，代码示例里可以放心写方括号。

## 六、独立页模板

后台「管理 → 独立页面 → 新增」，在右侧「自定义模板」里选择：

| 模板 | 作用 |
| --- | --- |
| 时间轴归档 | 按年折叠、按月分组，展示全部已发布文章 |
| 读者墙 | 按留言条数排序，前三名带金 / 银 / 铜牌 |
| 随机跳转 | 访问即 302 跳转到一篇随机文章，带 `no-store` 与 `noindex` |
| 投稿 | 前端投稿表单；待审核 / 草稿支持 `?edit=<cid>` 回改 |
| 快讯 | 按日期分组的时间流；页面自定义字段 `flash_cat` 填分类 mid 可限定分类 |
| 网址导航 | 分组卡片式站点导航，数据来自「网址导航数据」设置 |
| 标签归档 | 全站标签墙，按文章数排序、字号随热度渐变 |
| AI 助手 | Credit 计费的 AI 对话页（复用「AI 摘要」接口配置） |
| 抽奖 | 消耗 Credit 抽奖：九宫格、保底、直接兑换、我的记录 |
| 兑换商城 | 积分当钱花：兑换会员 / 单篇解锁 / 定制权益 |
| 广告投放 | 自助广告：选位、按天下单，支付并审核后上线 |

- **Credit 积分**：「设置 → 互动 → 积分与 AI」。任务：签到 / 评论 / 被赞 / 发文 / 开会员赠送，均有每日上限；余额与流水在个人中心「我的积分」。
- **站点抽奖**：「设置 → 变现 → 站点抽奖」。奖品池一行一个（`名称|权重|库存|类型|值`），支持保底必中与头奖直接兑换；挂件与页面就地抽奖。
- **兑换商城**：「设置 → 变现 → 兑换商城」。商品一行一个（`名称|价格|类型|值|库存|限购`），vip / 单篇自动发货，实物在付费管理台「最近兑换」跟进。
- **自助广告**：先开付费阅读，再开「设置 → 变现 → 自助广告」并定价；用户在「广告投放」页下单，付费管理台审核后上线；侧栏用「自助广告」（价目卡）与「投放广告」（展示）两个挂件。
- **投票**：正文写 `[poll multi end="2026-12-31"]问题\n选项…[/poll]`，一人一票、到期自动锁。
- **推广返佣**：「设置 → 互动 → 积分与 AI → 推广返佣」。用户分享带 `?ref=UID` 的链接，好友注册后其订单按比例返积分；个人中心可复制专属链接。
- 挂件统一在「模块管理台」摆放；功能未开启时管理员前台会看到设置提示卡，访客不可见。

## 九、文章自定义字段

编辑文章时「自定义字段」区域可填：

| 字段 | 取值 | 作用 |
| --- | --- | --- |
| `thumb` | 图片地址，每行一个 | 覆盖封面，最多取三张（三图模式用） |
| `mode` | `default` / `feature` / `gallery` / `bare` / `grid` / `title` / `compact` / `mosaic` / `item` | 单独覆盖这篇的卡片样式 |
| `side` | `left` / `right` | 单独覆盖封面位置 |
| `pin` | 任意非空值 | 显示「置顶」角标 |
| `series` | 系列名 | 显示「系列」角标 |
| `price` | 任意文本（纯数字自动加 ¥） | 清单卡（`mode=item`）左下角价格 |
| `spec` | 用 `|` 或 `,` 分隔，最多 4 项 | 清单卡规格胶囊，如「轻量 46KB \| 无依赖」 |
| `rating` | 0 - 5，支持一位小数 | 清单卡星级评分 |
| `buy` | http(s) 链接 | 清单卡「查看」外链按钮（新标签打开） |
| `source` | http(s) 链接 | 快讯页的「查看来源」外链（不填显示「阅读全文」） |
| `copyright` | 版权模板名称 | 选用「设置 → 文章页 → 版权模板」里对应的声明文本 |

## 十、常见问题

**Q：点了「生成文件」但浏览器里 `/sitemap.xml` 还是 404？**
A：确认文件写到了站点根目录（`__TYPECHO_ROOT_DIR__`）。若用容器部署，注意目录挂载权限。

**Q：搜索两个词（如「测试 卡片」）结果不对？**
A：Typecho 核心会把搜索词按 slug 规则规范化，空格在进入主题前就丢了，所有主题都一样。本主题的适配是：无空格时按字母段与中文段切分，并对长中文串补 2-gram 建议，空结果页给出「按词查找」词条。

**Q：代码块没有颜色？**
A：高亮是前端分词，语言取自 `<pre><code class="language-xxx">`。没有语言类名时会按内容启发式猜一次；猜不出来就保持单色。后台「代码高亮」开启时由 Prism 统一染色（语言缺省也能上色），关闭时回落到内置高亮器。

**Q：评论区的等级徽章怎么算的？**
A：按同一邮箱的已审核评论条数，阈值 1 / 5 / 10 / 20 / 40 / 80 / 160，对应「初见 / 常来 / 熟客 / 老友 / 资深 / 元老 / 镇站」。

**Q：评论没有嵌套 / 只能嵌套很浅？**
A：两处设置共同决定。①后台「设置 → 讨论」要勾选「启用嵌套评论」，最大嵌套层数默认 5；②主题「评论 → 嵌套折叠深度」控制前几层直接展开，超过的部分收进「展开 N 条回复」；③「评论 → 长讨论的展开方式」决定这些折叠是逐条点开、用一个顶部总按钮一次铺开，还是干脆不折叠。评论总数按全部已审核评论统计（含回复），不再只数顶层。

**Q：改了配置想回滚？**
A：工具页的快照列表，点「恢复」。恢复前会自动给当前状态存一份，所以误点也能回去。

**Q：主题升级会不会覆盖我的设置？**
A：设置存在 `options` 表的 `theme:ecod-theme` 里，跟主题文件分离。升级前建议先导出一份 JSON。

## 十一、服务器加固

主题内的 PHP 只需要 4 个入口能被浏览器直接访问：`api.php`、`media.php`、`pay-admin.php`、`manifest.php`，其余一律 403（Apache 由主题目录的 `.htaccess` 处理）。**nginx 不读 .htaccess**，请在 server 块里加等效配置：

```nginx
# 主题目录：只放行 4 个独立入口，其余 PHP 直连拒绝
location ~* ^/usr/themes/ecod-theme/(?!api\.php$|media\.php$|pay-admin\.php$|manifest\.php$).+\.php$ {
    deny all;
}
```

再按需叠加（均建议配置在站点层）：

```nginx
# HSTS（全站 HTTPS 且确认不再回退 http 后再开）
add_header Strict-Transport-Security "max-age=31536000" always;

# 上传目录禁止执行任何 PHP（优先级最高的加固之一）
location ~* ^/usr/uploads/.+\.php$ { deny all; }
```

> 📄 **完整对照手册见 [`docs/server-config.md`](docs/server-config.md)**：HTTPS 301 跳转、
> 静态资源长缓存、gzip/brotli 压缩、首屏大图与 LCP 的逐条配置与 curl 验证命令，
> 按该文档操作 Lighthouse Best-Practices 可直接满分。

**静态资源长缓存**（Apache 已由主题 `.htaccess` 内置，nginx 手工加）。
主题静态文件都是内容寻址的：`assets/dist/*` 文件名带哈希，其余带 `?v=filemtime`，
内容一变 URL 就变，可以放心发一年期 immutable：

```nginx
location ~* ^/usr/themes/ecod-theme/.+\.(css|js|png|jpe?g|webp|avif|gif|svg|ico|woff2?)$ {
    expires 1y;
    add_header Cache-Control "public, max-age=31536000, immutable";
}

# 预压缩静态文件：构建已产出 .gz / .br 副产物，直接吐文件、零在线压缩 CPU
# （brotli 模块需 ngx_brotli；没有就只开 gzip_static，两行可独立生效）
brotli_static on;
gzip_static on;

# 兜底压缩（处理没有预压缩产物的文本，如内联 HTML）
gzip on;
gzip_comp_level 5;
gzip_types text/css application/javascript application/json image/svg+xml;
```

主题自身已在 `public/header.php` 输出 `X-Content-Type-Options` / `X-Frame-Options` / `Referrer-Policy` / `Permissions-Policy`；CSP 建议先用 `Content-Security-Policy-Report-Only` 观察、收集到违反报告后再收紧为正式策略。

## 十二、前端构建（可选）

主题**开箱即用不依赖 Node**：仓库里 `assets/` 下的源码就是运行文件，不构建也完整可用。
构建是开发期的优化步骤：压缩、内容哈希命名、CSS 按族分包、关键 CSS 抽取、预压缩副产物。

```bash
cd build
npm install     # 仅装 esbuild 一个依赖
npm run build   # 产物写进 assets/dist/，manifest 同步更新
```

工作方式：

1. `build/build.mjs` 逐文件 minify（只压缩、不合并、不转译），产物落 `assets/dist/`，
   文件名形如 `ecod.a1b2c3d4.min.js`（内容哈希，内容变 → 文件名变），
   并附 `.gz` / `.br` 预压缩副产物（配合上面的 `gzip_static` / `brotli_static`）；
2. 同时生成 `assets/dist/manifest.php`（源路径 → 产物路径）；
3. PHP 侧 `core/lib/asset.php` 是唯一查询入口：`ecod_asset()`（前台）、
   `widget.php`、`admin/editor.php` 都先查 manifest，命中发哈希文件，
   未构建 / manifest 缺失 / 产物被删则自动回退源文件 + `?v=filemtime`；
4. **CSS 按页面族分包 + 分族关键 CSS 内联**：整份 `ecod.css` 构建期按「节的宿主
   模板族」切成 core / home / list / post / postext / user / page 共 7 个族文件
   （`PAGE_SETS`），页面只异步加载 core + 自己所属的族（`preload` + `onload` 转正，
   `<noscript>` 兜底），PJAX 跨族换页由 `ensurePageCss()` 补注入；
   `<head>` 内联的是「首帧骨架 + 本族首屏」的关键 CSS（`CRITICAL_BASE` /
   `CRITICAL_FAMS`，按页 93–118 KB，gzip 15–19 KB），首屏 0 阻塞且不重复下载
   首屏可见件；想调覆盖面改这两个数组——构建期自带「不漏节、不引用不存在的节」
   断言，改错会直接构建失败；
5. **JS 按页拆包**：`assets/js/ecod.global.js`（全站）+ `assets/js/ecod.post.js`
   （文章/独立页专属：目录、评论、朗读、收银台等 21 个模块），
   页脚按模板输出第二个 `<script>`，PJAX 进入内容页时动态注入——
   首页首屏 JS 体积约省四成；
6. 产物连同 manifest 一起提交进 git，服务器不需要装任何工具。

改了源码忘了构建也没关系——回退路径永远可用，只是没压缩。dist 里出现孤儿产物会被下次构建自动清掉。
