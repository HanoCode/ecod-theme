# 表情球 emotionId 契约（Grok Ball）

> 接新场景先查这张表，不要另造映射。ID 是引擎的契约：
> `00-09` 生命周期、`10-29` 情绪反应、`30-49` Agent 工作状态。
> 引擎全表见 `assets/js/vendor/grok-ball.js` 的 `EMOTION_SEED`。

## 用法（facade 句柄）

```js
ball.set('30')        // 切到指定表情（取消未完的 flash）
ball.flash('33', ms)  // 短表情，ms 后回 base
ball.celebrate(ms)    // = flash('33')
ball.holding()        // 是否在表演（外部联动避免覆盖）
Ecod.ballFlashAll(id, ms)  // 全员短表情：只有已加载且活着的球响应，绝不为此加载引擎
```

## 约定

- **失败分脸**：业务性失败（钱不够、审核、验证码）不用 34，34 只留给真正的故障。
- **庆祝归 celebrate / flashAll**：实例可能随 DOM 替换消亡（评论区），换页后仍活着的球（站宠）兜底。
- **小尺寸球传 `size`**：≤36 自动走引擎 lite 模式（省 orbit/zzz/彩带渲染层）。
- **新增挂载点**：容器 span + `aria-hidden="true"`，尺寸进 CSS §43；触发只调 `Ecod.ballMount`（懒加载引擎）或 `Ecod.ballFlashAll`（不加载引擎）。
