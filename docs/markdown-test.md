## 五、代码块（围栏式）

```php
<?php
// PHP 代码块示例
function hello(string $name): string {
    return "Hello, {$name}!";
}
echo hello("World");
```

```javascript
// JavaScript 代码块示例
const sum = (a, b) => a + b;
console.log(sum(1, 2)); // 3
```

```python
# Python 代码块示例
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print([fib(i) for i in range(10)])
```
