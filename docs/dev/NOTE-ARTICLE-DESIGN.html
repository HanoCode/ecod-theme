图文笔记：公众号图文 × 小红书笔记的文章类型

给现有博客体系加一种「图为主、文为辅、轻互动」的文章形态：文章级开关启用，详情页切换到笔记模板，列表可出笔记卡。本文件是唯一设计真源，实现时按 §09 落点执行。

  • 落地形态：文章级开关——单篇启用，其余文章零影响。

01

目标与边界

先定义「做到什么算完成」，后面每个决定都对着这一页检查。

要做到

  • 单篇文章可切换为笔记形态，正文内容零重写，只换外壳与排版节奏
  • 竖版 3:4 封面 + 最多 9 张图集，支持滑动浏览与放大查看
  • 话题标签、作者关注、点赞/收藏/分享互动条与现有体系同源
  • 移动端优先，桌面端退化为「窄栏 + 侧边互动」，不出现手机截图式的死板容器
  • 后台可在「设置 → 文章页」开关全局能力，单篇在编辑页切换

明确不做

  • 不做新数据表、不做独立频道路由（/notes），保持 Typecho 原生内容体系
  • 不复刻小红书的瀑布流首页与推荐算法
  • 不做图片滤镜/贴纸/文字编辑器（那是编辑器产品，不是主题）
  • 不改现有 6 种卡片模式的语义，笔记卡是新增第 7 种
  • 不引入第三方图床或 CDN 依赖
一个关键约束（先记住）：列表版式已由 ecod_list_force_mode() 统一接管，不再读取文章字段 mode。所以笔记形态在列表里的呈现不能依赖文章字段自动生效，必须作为独立版式参数 note 由列表/模块显式选择（见 §10.6）。
02

双平台拆解：拿什么、丢什么

两个平台不是审美差异，而是两种阅读契约：公众号是「读一篇」，小红书是「看一张再读两句」。

维度微信公众号图文小红书笔记本方案取法
入口标题 + 方形小封面，标题决定点击竖版封面占 70% 视觉，封面即内容竖版 3:4 封面 + 标题压在封面下方（取小红书）
排版居中窄栏、段间距大、图居中带图注短句分段、大量空行、emoji 做项目符号窄栏 + 大段距，段长上限 3 行（两者合并）
图片插图式，随文流动，可长图图集式，横滑、计数、点开放大首屏图集横滑，正文内图保持随文（取小红书）
元信息作者 + 时间 + 阅读量作者 + 时间 + 点赞/收藏/评论数作者行加关注按钮，互动数放底部条（两者合并）
收尾「点赞 / 在看 / 分享」三连 + 关注引导话题标签 + 相关推荐话题标签 + 文末统一互动条（取小红书）
阅读节奏线性、长、可分段折叠碎片、短、可一眼看完默认展开，超过阈值才折叠（复用现有 EShowMore）
不适合的强 SEO、代码块、长表格深度内容、目录导航笔记模式关闭目录与阅读进度，保留 SEO 全文

现有文章页已经有的能力（直接复用，不重复造）

门禁体系

密码锁 ecod_has_password、付费锁 ecod_pay_access、试读截断，笔记模式必须走同一判定。

图片管线

ecod_thumbnails() 已实现「字段 → 正文图 → 图池」三级回退与裁剪代理。

互动内核

点赞为 toggle（api like）、关注按钮 ecod_user_follow_btn()、评论计数。

03

设计取向

一句话：用公众号的克制，承载小红书的节奏。拒绝「把手机 App 截图搬进网页」。

五条设计原则

1
图先于字首屏 60% 面积给封面，标题在其后而非其上。
2
窄栏强制正文栏宽上限 640px，行高 1.9；任何宽度都不放满屏。
3
一段一口气段落视觉长度 ≤ 3 行，作者写作时不必手动拆，由 CSS 控制段距即可。
4
互动贴边不悬浮移动端底部条吸附，桌面端左侧竖排，避开正文阅读区。
5
无第二主色全部沿用设计令牌，封面暖色由内容图片提供，界面不加粉色。

与普通文章的差异（作者能感知到的）

标题
22px / 700，左对齐，最多 2 行；不显示分类徽标
封面
3:4 竖版，16px 圆角，角标显示 1/6
正文
16px / 1.9，段距 1.1em，宽度 640px
图片
全宽圆角 12px，图注 12px 居中灰字
标签
蓝色胶囊，最多 8 个，点击进标签归档
目录
不生成，不显示浮动目录与阅读进度
评论
保持原样，位置在互动条之上
04

信息架构

从上到下的阅读顺序即结构。左为移动端线框，右为桌面端退让规则。

① 顶部导航（复用现有 header，滚动时显示作者简版）
② 标题区：标题 2 行 + 分类可选
③ 封面 / 图集：3:4 横滑 + 计数角标 + 圆点
④ 作者行：头像 + 昵称 + 分组 + 关注
⑤ 元信息：日期 · 阅读 · 字数（弱化，12px）
⑥ 正文：短段 + 小标题 + 引用 + 图注
⑦ 话题标签：胶囊，最多 8 个
⑧ 底部互动条：评论输入 + 赞 + 藏 + 分享（吸附）
⑨ 评论列表（原样复用 comments.php）
⑩ 文末模块区（模块管理台 bottom_content 原样）

蓝底为笔记模式新增区块，其余沿用现有渲染。

桌面端（≥1024px）退让规则

  • 正文列固定 640px 居中，两侧留白，不做双栏阅读
  • 互动条从底部改为左侧竖排 40px 圆形按钮，position:sticky，不遮挡文字
  • 右列显示作者卡（关注 + 简介 + 3 篇同标签推荐），可后台关闭
  • 封面在图集模式下最大高度 520px，超出按比例居中裁切
  • 图集支持键盘 ← → 与 Esc，鼠标悬停露出左右箭头

平板（768–1023px）

单列 100%，底部互动条保留；右列作者卡移入正文末尾（复用 authorbox 模块，避免重复输出）。

05

数据与字段

不建表、不迁移。全部落在 Typecho 原生自定义字段（fields 表），随文章删除自动清理。

5.1 新增 / 变更字段

字段控件取值默认说明
note下拉'' / on''笔记模式开关。为空即普通文章，零影响
note_tags单行文本空格或逗号分隔，最多 8 个''留空时自动取文章标签（$this->tags）前 8 个
thumb（复用）多行文本每行一个图片地址''说明文案改为「第一张为封面，笔记模式最多读取 9 张」

5.2 图集回退链（复用 ecod_thumbnails()）

1
thumb 字段逐行读，非空即入列；首项固定为封面。
2
正文图片不足 9 张时，正则提取 <img src> 补齐；锁定/付费未授权时跳过（不泄漏内容）。
3
全站图池EThumbnail 兜底，保证「有图可显示」，与现有列表卡片行为一致。
4
一个都没有退化为无图笔记：标题 + 正文，图集区不输出，不显示空框。
裁剪预设新增一个：core/content/thumbs.php 的 ecod_thumb_presets() 加 'note' => [480, 640]（3:4，2x 由浏览器处理）。列表笔记卡复用同一预设，避免两种比例导致封面跳变。

5.3 字段读写约定

读取

统一走 core/content/note.php 的三个函数，模板层不直接摸 $archive->fields：

  • ecod_note_on($archive): bool
  • ecod_note_gallery($archive, $limit): array
  • ecod_note_tags($archive): array

写入

themeFields() 声明控件 → admin/fields.js 接管为可视化面板，原生 input 保留为隐藏提交载体，保存链路完全不变（与现有 7 个字段同一套做法）。

07

图集、桌面版与列表卡

三块最容易做坏的地方，单独定死。

7.1 图集浏览（横滑 + 查看器）

交互规格

滑动CSS scroll-snap-type: x mandatory，每屏一张，纵向滚动不受影响
指示右下 n / N 角标 + 底部圆点（当前项变长条）
放大点击进入查看器：全屏黑底、图片 contain、左右箭头、Esc 关闭
键盘← → 切换，Esc 关闭，焦点锁在查看器内
手势移动端左右滑切换；下滑 80px 关闭
性能首图 fetchpriority=high，其余 loading=lazy，decoding=async

边界情况

  • 只有 1 张：不显示圆点与角标，退化为单张封面
  • 超过 9 张：第 9 张封面右下显示 +N，点击仍可翻到全部
  • 锁定 / 付费未授权：整个图集不输出，只留标题与门禁卡（防止截图式泄漏）
  • 图片加载失败：显示占位底色 + 图注，不撑破布局
  • PJAX 切页：查看器节点挂在 shell 内，事件用委托绑定，切页自动失效不残留

08

交互与功能分级

P0 是「不做就不算完成」，P1 是「上线后第一轮补」，P2 是「看数据再说」。

级别功能说明后端
P0笔记模板渲染标题 / 封面 / 作者行 / 正文窄栏 / 标签，走 post.php 分支无
P0图集横滑 + 计数 + 圆点纯 CSS scroll-snap，无 JS 也能用无
P0图片查看器全屏、键盘、手势、焦点管理无
P0话题标签note_tags 优先，回退文章标签无
P0互动条（赞 / 藏 / 分享 / 评论）点赞复用现有 toggle；收藏复用已上线的 fav 体系（data-ecod-act="fav"，无需新表）；分享走系统分享，降级复制链接已有
P0门禁复用密码锁、付费锁、试读截断全部生效，锁定态不出图集已有
P0暗色 + 响应式三档断点：≤767 / 768–1023 / ≥1024无
P1收藏已随 P0 落地：主题本就有 fav 体系（favs_state 接口 + 个人中心），互动条直接复用，原计划的 ecod_keeps 新表不再需要已有
P1列表笔记卡版式新增版式参数 note：3:4 网格 + 标题 2 行无
P1封面叠字开关ENoteCoverText：把标题压到封面底部无
P1图集角标 +N超过 9 张时提示还有多少无
P2模块管理台「笔记精选」模块 ✅ 已落地在首页/侧栏摆放笔记卡列表，按标签或专题筛无
P2九宫格图集 ✅ 已落地图多时首屏改九宫格，点开查看器无
P2结构化数据 ✅ 已落地JSON-LD ImageObject 列表 + 作者 sameAs无
为什么收藏要单列：现有互动只有点赞 toggle。收藏是「稍后再看」的强需求（小红书笔记的核心动作之一），但需要用户维度存储与列表页。放在 P1，避免 P0 拖长交付。

后台设置

三层：主题设置（全局能力）→ 文章编辑页（单篇开关）→ 模块管理台（摆放）。

9.1 主题设置 · 「内容 → 文章页」新增小节「图文笔记」

选项控件取值说明
ENote开关on / off（默认 off）总开关。关闭后编辑页字段隐藏、前台不解析，已启用的文章回落普通样式

验收与分期

P0 完成后按这张清单逐项打勾，任一项不过就不算交付。

P0 验收清单

  • 开关隔离：未启用的文章，DOM 与样式与改动前逐字节一致
  • 字段回退：thumb 为空时自动用正文图，图池兜底仍生效
  • 图集：横滑一次一张、角标正确、单图不显示圆点
  • 查看器：点击打开、← → 切换、Esc 关闭、焦点回到触发图
  • 门禁：密码文章与付费文章锁定态下无封面、无图集
  • 互动：点赞 toggle 正确回写计数，未登录点按给出登录提示
  • 标签：note_tags 优先，为空回退文章标签，链接可跳归档
  • 暗色：切换后标签、图注、角标对比度 ≥ 4.5:1
  • 响应式：390 / 768 / 1440 三档无横向滚动、无遮挡
  • PJAX：连切三篇文章后无重复遮罩、无重复绑定
  • 构建：node build/build.mjs 全量产物更新、断言通过
  • 性能：9 图笔记移动端 LCP ≤ 2.5s（本地 4G 模拟）

P0

收藏链路 + 列表笔记卡版式 + 封面叠字 + 编辑页预览。目标：笔记能进列表、能被收藏。

P2 落地记录（2026-11-01）： ① 九宫格图集 ENoteGrid：开为方格拼贴（≤4 张 2 列 / ≥5 张 3 列，3 列放 4 张会留空位），样式在 §49（关键 CSS，首帧不裸奔），格内复用 ecod_noteart__zoom 与 __more；initNote 改为「track 允许缺席」——横滑与九宫格共用同一查看器，圆点仅横滑形态渲染；封面叠字与九宫格互斥（方格上叠字不可读）。 ② JSON-LD：ecod_note_ld() 输出独立一段 SocialMediaPosting（ImageObject 数组 = 实际下发的图集，480×640；author + sameAs = 作者主页；keywords = 话题标签），不并入 seo.php 的 Article 图——canonical 与 permalink 可能不同，悬空 @id 引用比不引用更糟；锁定/付费未授权时图集为空，本段整体不输出，付费内容不会结构化成可抓取元信息。 ③ 笔记精选模块 note-pick：参数 = 标题 / 取数（最新、最热=阅读+评论加权、随机）/ 标签筛选（slug 或 mid，逗号分隔）/ 条数 / 列数 / 是否显示点赞数；EcodPostQuery 新增 noteonly（fields 表 note=on 的 cid 集合，>2000 退化为不筛）与 tags（两步查询，标签不存在直接返回不静默降级为全站）；样式 §52 放 core 族——模块可出现在任何页面侧栏，不能依赖只在 list 族下发的 §50，侧栏自动切 78px 行式紧凑卡；首页被页面构建器接管时模块管理台的 home_bottom_content 不参与渲染，验收走的侧栏区。
实现版命名修正（2026-11-01）：CSS 类前缀最终为 ecod_noteart__——旧样式表里已有 .ecod_note（正文提示块）及其 __head / __body 子类，若新组件沿用 ecod_note__ 会被提示块规则污染（作者行被 flex 横排、图集塌缩）。新增内容组件前先全局 grep 旧类名是硬性动作。
