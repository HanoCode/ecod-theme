01 · 设计策略

DOM 不动，CSS 重生

模板骨架、节点层级、包裹关系与 Joe_2 完全一致（便于后续合并上游修复）；仅替换类名/ID 前缀与样式实现，CSS 零继承、全部重写。

① DOM：1:1 保持

保留 #Ecod > .ecod_container > .ecod_main / .ecod_aside 三层骨架；public/header|aside|footer 的嵌套顺序、.ecod_card 的四种模式分支都不变。好处：模板渲染逻辑、AJAX 输出、上游更新均可平移。

② 命名：统一前缀替换

结构不变但标识换成主题命名：joe_header → ecod_header，#Joe → #Ecod。JSON 接口字段、Cookie 名同样改前缀，与 Joe 彻底隔离，避免同站共存冲突。

③ CSS：零继承重写

不引用任何 joe.*.css。以 tokens + 组件分层重写：base（reset/变量）→ layout → components → pages，输出单一入口 ecod.css。

header 四分区与操作簇 2026-10-30 修订

参考成熟站点的 header 构成，把导航条从「logo + 纯文字导航 + 搜索框 + 头像」升级为四个分区：品牌区 → 主导航 → 操作簇 → 用户区，操作簇与导航之间用 1px 竖分割线（.ecod_nav__sep）分组。不做电商语境的购物车 / 货币选择器。

分区构成
① 品牌区无 ELogoImage 时输出默认图形块（.ecod_nav__logo-mark，主色圆角方块 + 站名首字）+ 字标；上传 logo 图后按现有逻辑渲染图片（ELogoBoth 仍可追加字标）
② 主导航每项可配 icon / badge 字段（字段定义见 §03.5 表）；有 icon 时在文案前渲染 15px 线性 sprite 图标，透明度 .78；badge 为右上角小胶囊（.ecod_nav__badge，danger 色，白字 10px），配了才渲染。移动抽屉不渲染 icon/badge（保持紧凑列表）
③ 操作簇从左到右：分割线 → 搜索按钮 → 深浅切换 → 分割线 → 用户区。ESearchPanel=on 时常驻搜索框收敛为 34px 圆形图标按钮（.ecod_nav__searchbtn），点击走 C4 面板的 capture 唤起，⌘K / dock 入口不变；=off 时保留原搜索表单形态兜底。深浅切换按钮复用 data-ecod-theme-toggle 机制（现有 dock 同款），点击循环 light/dark 并写 localStorage，EDark=auto 时初始按系统偏好
④ 用户区保持现状：登录态头像下拉 / 游客登录弹层入口，不改结构，仅纳入操作簇的间距节奏

兼容：icon / badge 为可选字段，旧 ENavSets 数据无此字段时导航自动退化为纯文字；「更多」下拉不渲染 icon/badge。二级菜单子项渲染 icon（见下方图标网格说明）。操作簇全部元素在 #ecod-shell 之外的 header 内，PJAX 换页不受影响。

29 · 后台交互

设置项的条件联动

设置项之间存在真实的生效依赖：总开关没开，子项填了也不生效。后台按「只看当下一步要填什么」组织：条件不满足的字段直接隐藏，控制字段下方给出隐藏数量提示，整组失效时在分组顶部给出提示条。

三段式呈现

① 字段级隐藏

子项条件不满足时整行移除出视野，不留占位、不置灰。父项被隐藏时，其下级字段一并隐藏（链式求值，最多 4 轮收敛）。

② 父项计数提示

控制字段下方追加一行浅色小字：另有 3 项关联设置已隐藏（开启后显示）。用户知道关掉它顺手关了什么，也知道打开后会出现新内容。

③ 分组级提示条

整组设置因外部开关失效时（如全站评论关闭、侧栏设为「无侧栏」），分组顶部出现提示条，附「去开启」按钮，一键跳回控制该组的字段并高亮。

条件表达式

挂在控件上的 data-ecod-show-when，挂在分组面板上的 data-ecod-pane-when，同一套语法。

写法含义
ECommentProvider:twikoo控制字段等于该值
ECommentProvider:twikoo|waline等于其中任一值
ECardMode:!=bare|title不等于其中任一值（前置 !）
ELogoImage:!empty该字段非空（empty 为判空）
ECode:on,EFloatToc:on逗号分隔为「且」，全部满足才显示
降级JS 未加载时所有字段照常显示并可保存，联动只是可见性增强，不影响任何取值与提交。

C1 · 列表排序

URL 契约 ?sort=recent|views|hot，缺省 recent。选项本身是链接，关掉 JS 也能用；JS 只负责展开与关闭。

项规格
生效范围index / category / tag / author / search 五种归档主查询
排序字段views → contents.views DESC；hot → commentsNum DESC；两者都以 created DESC 兜底
置顶优先pin 字段非空的文章浮到流的最上面（首页 / 分类 / 标签 / 作者四种归档；search 不置顶——搜索要的是相关度）。实现：主查询 LEFT JOIN table.fields（name='pin' AND str_value<>''）按 str_value DESC 排首列，JOIN 条件收在 ON 里不产生重复行；必须同时 select('table.contents.*')——框架 fields 默认 *，JOIN 后会带出 fields 表的同名列（cid）覆盖正文数据。置顶内部按 created DESC 排序；空值 pin 字段（写作页关闭置顶留下的空串行）不参与 JOIN，不受影响。分类 / 标签页的置顶只在该归档自己的结果集里浮——不在该分类的置顶文不进结果集，自然不会乱浮。三种排序（recent/views/hot）下置顶都最优先；轮播 source=pin 与角标逻辑不变，ecod_pinned_cids() 仍归轮播专用
不做点赞排序点赞按行存储（ecod_likes 一人一行），排序要子查询或冗余计数列，为一个排序项改表不值
落点core/sort.php（钩子）、components/home/sort.php（浮层）、components/home/list.php（挂载）

动效与过渡规范

动效令牌（--ecod-dur-* / --ecod-ease）早在 v2 就写进了 :root，但审计实测：全站 165 处 transition 中 137 处（83%）没写 timing-function，实际跑的是浏览器默认 ease；--ecod-ease 全站只被引用 1 次。令牌建了不用，等于没有。本节把动效从「随手写的过渡」升级为「有口径的系统能力」，作为后续所有动效改动的唯一依据。

为什么值得做

现状诊断
137 / 165 处 transition 无曲线浏览器默认 ease 是 cubic-bezier(.25,.1,.25,1)，起步肉、尾巴拖，是「廉价感」的最大来源；且它和项目自己定的 Material 曲线不是同一条，全站节奏不统一
transform-origin 全站仅 1 处（默认值 50% 50%）所有弹层都从中心缩放，而不是从触发它的那个按钮长出来——用户的空间认知断层
0 处 animation-delay列表卡片同时砸下来，没有先后，看不出内容层级
10 个 keyframes 全 ease「弹出来」的东西没有回弹，缺物理重量感
PJAX 换页只有顶部加载条新旧页面之间没有连续性，读感是「刷新」而不是「翻页」

对标水位：Rare UI 的 fluid-orb（单文件 WebGL、零依赖、prefers-reduced-motion 只渲一帧）与 transitions.dev 的 43 组精调动效（origin-aware 展开 / spring 回弹 / stagger 级联 / FLIP 变形）。本站不追求那类视觉奇观，只吸收可度量、低成本、全局一致的部分。

--ecod-dur-fast140ms同层状态切换：hover / focus / 颜色 / 描边 / 小图标

曲线（两条，用途互斥）

令牌值适用
--ecod-easecubic-bezier(.4, 0, .2, 1)通用：位移、尺寸、颜色、阴影、展开收起。全站默认曲线

linear 保留给两处专用语义：进度条（进度必须匀速）、visibility 等离散属性（timing 无实际意义，写成 linear 语义更准确）。除此之外不应出现第三种曲线。

七条强制规则

#规则
1任何 transition / animation 必须显式声明时序函数，禁止回落浏览器默认 ease。多段 transition 每段都要有（timing-function 不跨段继承）。
2入场类动画统一用 --ecod-dur-enter；出场类用 --ecod-dur（出场快于入场，符合「离开不必挽留」的直觉）。
3「弹出来」的元素用 --ecod-ease-pop，其余用 --ecod-ease。全站不出现第三条自定义曲线。
4列表入场采用级联：animation-delay: calc(min(var(--i, 0), 12) * 40ms)。序号上限 12——超出的子项按 12 计算，避免长列表末尾等半秒才出现。
5所有从触发点展开的弹层（下拉 / 右键菜单 / 用户菜单 / 搜索面板），transform-origin 由 JS 写入触发元素中心点（--ox / --oy），缺省回退 50% 50% 保持旧行为。
6prefers-reduced-motion: reduce 下：级联、回弹、View Transition 全部跳过；仅保留 opacity 级别的必要过渡。CSS 与 JS 两侧都要守（CSS 用媒体查询，JS 统一走 Ecod.reduceMotion()）。
7只动 transform / opacity / filter 做动效；禁止用 transition: all，禁止对 width / height / top / left 做长过渡（布局抖动）。
