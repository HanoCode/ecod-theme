01 · 总览

背景与范围

瓜奇（guaqi.com）= Nuxt 3 无头 WordPress + 低代码模块前台。本稿只吸收与其现有体系兼容、Typecho 单机可实现的部分，形成 5 个功能包。

吸收原则

  • 令牌先行：所有新组件消费统一卡片令牌（§2.1），不各自声明圆角/阴影——对齐瓜奇 gq-card-* 体系。
  • Widget 化：榜单、磁贴区全部做成 EWidgets 模块类型，走现有管理台 + 自由投放，不加区域白名单。
  • 复用已有内核：付费解锁挂进现有 paywall 四层门禁；图标选择复用 ECOD_NAV.iconSvg 可视化网格。
  • PJAX 安全：所有新组件仅在 #ecod-shell 内渲染，无 shell 外常驻 UI。
  • 不做：拖拽式可视化构建器、多语言、商城/优惠券、签到积分（依赖用户体系，暂缓）。

设计令牌

一处声明，全站消费。新增变量挂在 :root 与 .dark（或现有主题暗色钩子）上，所有 §05 组件只引用不覆写。

:root {
  --ecod-card-radius: 14px;        /* 外层卡片 */
  --ecod-card-radius-sm: 10px;     /* 内嵌块 / 磁贴 */
  --ecod-card-pad: 16px 18px;
  --ecod-card-surface: #fff;
  --ecod-card-border: #e8ebf1;
  --ecod-card-shadow: 0 1px 3px rgba(24,32,52,.05), 0 6px 20px rgba(24,32,52,.05);
  --ecod-card-shadow-hover: 0 6px 16px rgba(24,32,52,.10), 0 16px 40px rgba(24,32,52,.10);
  --ecod-card-lift: -2px;          /* hover 上浮距离 */
  --ecod-card-motion: cubic-bezier(.33,.12,.15,1);
  --ecod-dur-fast: .22s;           /* hover / 按钮 */
  --ecod-dur-slow: .45s;           /* 图片渐入 */
}
.dark {
  --ecod-card-surface: #1d212e;
  --ecod-card-border: #2c3142;
  --ecod-card-shadow: 0 1px 3px rgba(0,0,0,.3), 0 6px 20px rgba(0,0,0,.22);

迁移约定：现有 data-shell 注入的模块壳、paywall 卡、AI 摘要卡、热门榜、磁贴全部改引上述变量；允许组件级微调 padding，禁止覆写 radius/shadow。

02 · UI 设计规范

间距 · 圆角 · 阴影

间距（4 基数）

组件内边距 16px 18px；条目行距 8px 0；图标-文字 gap:8px；磁贴网格 gap:10px；分区块间距 24px。

圆角

卡片 14px；磁贴/内嵌块 10px；图标底 12px（38px 方块）；徽章 999px；序号块 5px。

阴影

静态双层极淡；hover 双层加深 + translateY(-2px)；禁止 scale 大于 1.01，避免文字发虚。

02 · UI 设计规范

动效

只保留两类动效 + 一条 PJAX 约束（对应 F5）。

动效参数触发
卡片 hovershadow→hover 态 + translateY(-2px)，.22s cubic-bezier(.33,.12,.15,1)可点击卡片 hover
图片渐入opacity 0→1，.45s ease；占位底色 #eef0f5（深色 #1f2330）img.onload 加 .on
PJAX 约束过渡只在 #ecod-shell 内容层做，组件不得自带入场动画，避免 PJAX 切页闪跳—
降级：@media (prefers-reduced-motion: reduce) 下 hover 仅保留阴影变化，渐入时长归零。
03 · 功能设计

F1 · AI 摘要卡

文章正文前展示预生成摘要；瓜奇为运行时流式生成，Typecho 单机改为「后台预生成 + 前台静态渲染」，可选前端打字机回放。

① 写作端文章自定义字段 ai_summary 存摘要文本；可选 ai_summary_model 存模型名
→
② 渲染层post.php content 输出前检测字段，非空则渲染摘要卡；空则整卡不输出
→
③ 交互默认全文直出；开关开启时打字机回放（rAF 驱动，尊重 reduced-motion）；点击「展开原文」滚动至正文

结构

  • 头部：渐变 logo 块（22px/圆角7）+「AI 摘要」+ 圆点标签（生成模型名）
  • 正文：≤ 200 字，超长折叠「展开」
  • 底部：免责声明「由 AI 生成，仅供参考」+ 字数 {n} 字
  • 底色：accent-soft 135° 渐变叠 card-surface

边界情况

  • 付费文章：摘要卡在门禁 外（摘要可读，正文锁）——门禁顺序：AI 卡 → 试读 → 解锁卡
  • feed / 搜索 / excerpt：不输出摘要卡（沿用 ecod_pay_feed_guard 剥除思路，避免重复内容）
  • PJAX：字段随文章 HTML 一起到达，无额外请求
/* 渲染伪代码 —— core/ 内新增，禁止引用主题模板局部变量（独立闭包） */
function ecod_ai_summary_render($cid, $fields) {
  if (empty($fields['ai_summary'])) return '';   // 无字段零输出
  return '<div class="ecod-ai-sum">…</div>';      // 结构见 §05
}
03 · 功能设计

F2 · 评论解锁付费

paywall 新增解锁模式 comment：发表任意一条过审评论即解锁当前文章付费内容。与现有「购买解锁 / VIP 解锁」并列。

① 门禁判定ecod_pay_teaser_balance() 判断链新增分支：文章 paywall_mode 为 comment 时，检查解锁凭证
→
② 凭证评论入库成功后种 cookie ecod_pay_c_{cid} = HMAC(cid+uid+ts)；读取时服务端验签，不信任纯前端状态
→
③ 解锁反馈验签通过 → 门禁放行；页面顶部显示一次性提示条「已解锁」，2s 后淡出

解锁卡 UI（未解锁时替换购买卡）

  • 锁形图标底 40px/圆角12/lock 色
  • 文案主标「评论后解锁全文」+ 副标「发表评论即可阅读付费内容」
  • 内置迷你评论框：输入框 + 提交按钮（复用 api.php 现有评论接口，验证码逻辑照旧）
  • 试读尾部保留渐隐遮罩（高度 52px，向上渐隐 + 横纹），暗示下文

门禁四层适配

层改动
post.php 硬门禁验签通过则放行 content
ecod_excerpt 列表层不变（列表永远摘要）
ecod_pay_feed_guard不变（feed 永剥除）
搜索剥除不变
安全红线：① HMAC 密钥用站点 authCode 派生；② cookie 仅本站 + httpOnly + 30 天；③ 评论进待审时 不发凭证，过审才发；④ 删除该评论不回收凭证（简化，文档明示）。绝对禁止改动 EWidgets 行存 JSON 相关代码。

F3 · 热门榜 Widget

对应瓜奇右栏「热门帖子」。作为 EWidgets 新模块 hot_posts，自由投放到任意区域。

数据口径

  • 指标单选：浏览 / 评论 / 加权（默认加权：views + comments×20）
  • 周期：近 7 天 / 近 30 天 / 全部（默认 7 天）
  • 排序后取前 N（默认 5，上限 10）；排除付费文章外的加密/隐藏内容
  • 缓存：结果缓存 10 分钟（option 行时间戳比对），避免每 PV 聚合查询

渲染

  • 头部：icon 点 +「热门文章」+ 可选「更多」链接
  • 条目：序号块（Top3 专用色）+ 标题单行截断 + 右侧元信息（浏览 · 评论）
  • 序号计数器用 CSS counter-reset/counter-increment，不写死序号文本
  • v2：头部可选周期 Tab rangeTab（7天/30天/全部，吸收 Zibll 排行榜交互），三组结果一次性预渲染、纯前端切换，无二次请求
  • 整卡走 §2.1 令牌；区域密度 data-density 照常生效

F4 · 磁贴快捷区 Widget

对应瓜奇首页 tileZone。一排 icon 磁贴，跳转导航/分类/外链，适合首页顶部或侧栏。

条目模型（管理台可增删、拖拽排序）

字段说明
iconSVG，复用构建器可视化图标网格（ECOD_NAV.iconSvg）
label文字，≤6 字建议
href内链/外链；外链自动 rel="nofollow"
color图标底色，预设 6 色（accent/green/amber/red/violet/gray）
badge可选角标文本（如「新」「HOT」），红/绿两色

版式参数

  • 列数：3–6（默认 5）；≤640px 自动 min(3, n)
  • 样式：卡片（默认）/ 无框；无框模式仅图标+文字，用于透明底
  • 每区上限 20 条目，与 EWidgets 区域上限一致
  • 磁贴为 <a>，整块可点；hover 走 §2.5 卡片动效
payload 规范：style/列数等字段必须进构建器 payload()（吸取导航套 style 静默丢失的教训）；字段白名单若涉及导航复用，两处白名单（ecod_nav_norm_item / ecod_nav_resolve_item）同步。

F5 · 卡片动效令牌化

改造点集中在渲染层与 CSS，模板零改动。

  1. ecod_render_block() 的 ob 缓冲注入逻辑扩展：模块根节点补 class="ecod-card-motion"（与现有 data-shell 注入同点，不加新钩子）。
  2. CSS 新增令牌（§2.1）+ 两条规则：.ecod-card-motion:hover 与 .fade-in-image。
  3. 列表缩略图统一加 fade-in-image：onload 置 .on；PJAX 换页后由 shell 内事件委托对 img[complete] 立即补类，防止缓存图永远透明。
  4. prefers-reduced-motion 降级（§2.5）。
验收口径：浅/深主题下卡片 hover 阴影、上浮距离一致；图片渐入在 PJAX 往返后无闪烁；无任何 scale ≥ 1.01 的动效。

F6 · 付费资源卡

来源：Zibll 付费下载卡。paywall 展示层升级——purchase 门禁用本卡，comment 门禁用 F2 解锁卡，两者占据试读尾部同一位置。

结构（左图右文）

  • 预览图 186×130（文章首图或自定义字段），hover 显「点击预览」，点击灯箱放大
  • 徽章行：金底「付费资源」+ 语义附加（支持退款 / 会员免费）
  • 价格行：现价 24px 加粗 + 划线原价 + 会员档位标签
  • CTA：渐变购买按钮 → 跳转 page-cashier.php 现有收银台；旁挂已售/浏览数
  • 元数据表：两列虚线分隔 grid（大小/更新时间/系统/语言/退款/有效期）
  • 已购态：整卡替换为绿色已购条 + 下载按钮

字段来源

数据来源
价格 / 原价 / 会员档paywall 配置（真源 docs/paywall-design.md）
资源大小 / 系统 / 语言 / 退款自定义字段 pay_meta_*，缺失项整行隐藏
预览图自定义字段 pay_preview，缺省回退文章首图

降级原则：所有元数据字段可缺省——全缺省时自动退化为现有解锁卡版式，保证老文章无需补字段。展示层只读 paywall 状态，不改门禁判定逻辑（四层门禁零改动）。

F7 · 聚合 Tab 卡 Widget

来源：Zibll 首页聚合文章卡。一个模块内多个 tab 按分类/标签聚合，信息密度约为普通列表 widget 的 3-4 倍，适合首页大区块。

结构

  • 头部：tab 行（下划线 active，3-5 个）+ 右侧排序 pills（最新/热门/评论）
  • 内容：双列图卡（64×48 圆角 8）+ 标题两行截断 + meta（浏览 · 评论）
  • hover：标题变 --ecod-accent，图片走 F5 渐入

数据与交互

  • 每个 tab = 一个分类/标签查询，条数 ≤ 8；全部 tab 一次性预渲染，切换纯前端 display，无二次请求
  • 空分类 tab 自动隐藏；tab 全空则整卡隐藏
  • 排序 v1 仅「最新」生效，热门/评论为预留态（数据已含计数，后续可切）
  • PJAX：预渲染 DOM 随 shell 到达，切换事件用 shell 内事件委托

落地差异记录（实现 vs 设计稿）

项实现方式与设计稿差异及原因
F5 动效令牌 主题已有完整令牌体系（ecod.css §0/§12）与图片渐入（data-ecod-img blur-up），未重复造轮子；新增 html[data-motion] 属性 + ECardMotion 开关 + §14 组件样式节 不引入 --ecod-card-* 新令牌——主题设计语言是「卡面靠描边不靠阴影」（§4.3），hover 上浮只用于磁贴等新组件
F1 AI 摘要 增强既有 EAI 异步系统（api.php action=ai + 缓存 + 生成锁）：缓存加记模型名，前端补模型角标 / 字数统计 / EAIMotion 打字机；付费锁定时也显示（摘要可读） 不做自定义字段预生成——既有异步生成 + 内容 hash 缓存已等效且免维护
F2 评论解锁 ecod_pay_access() 新增 reason=comment 分支；读时验证 comments 表（登录按 ownerId、游客按 Typecho 记住邮箱 cookie），不落 HMAC cookie 优于设计稿：删评 / 转待审自动上锁，无凭证伪造面；不内嵌表单（防垃圾令牌 / Turnstile 必须走原生评论路由），解锁卡按钮平滑滚动聚焦评论区
F3 热门榜 现有 rank（周期 tab）/hot 复用，EcodPostQuery 新增 order=weighted（views + comments×20，views 列缺失退化评论序），管理台选项补「加权热度」 周期 Tab 设计稿落地前已存在（rank 模块），零新增
F4 磁贴区 新模块 tile-zone（home/aside 通用，跨区回落）：repeater 条目 icon/label/href/color/badge + cols 3-6 + card/plain；icon 用 ecod_icon_names() 白名单文本输入 暂不接可视化图标网格（导航构建器的 iconSvg 选择器是 admin 专有交互，复用成本高），先用图标名文本 + 6 色预设
F6 资源卡 新函数 ecod_pay_resource_card()：EPayResourceCard 开 + 单篇可购 + 有预览图或任一 pay_meta_* 时替代默认付费卡；pay_preview 预览 + 元数据 dl 表 + 划线原价 已售次数无数据源，暂显示浏览量；门禁判定四层零改动
F7 聚合 Tab 卡 新模块 tab-posts：terms 多选分类作 Tab（最多 5 个），全部 Tab 一次性预渲染，前端切换（Ecod.initTp() 进 global.js，PJAX 安全）；空 Tab 自动隐藏 排序 pills v1 未上——只有「最新」一种实际排序，放假控件不如不放；数据已含计数，后续可加
