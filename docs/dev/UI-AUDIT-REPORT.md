## 一、总体评估

**结论：骨架优秀，细节欠打磨。** Ecod 的工程底座已达到甚至超过部分参考主题：

| 维度 | 现状 | 对标水位 |
|---|---|---|
| 设计令牌 | `ecod.css` 头部完整令牌（色/圆角/阴影/布局/字体/暗色） | 达到 Puock 水位 |
| 可访问性 | `:focus-visible`、skip link、`.ecod_sr`、aria-label | 多数参考主题没有 |
| 后台设置 | 12 分组 + 侧边导航 + 块系统（拖拽排序）+ 快照 + 导入导出 | 超过 Joe，接近 handsome |
| 工程质量 | schema 自愈、N+1 预取、蜜罐+HMAC 评论防刷 | 全部参考主题之上 |

真正的差距在三类：**① 视觉打磨不一致；② 交互状态不完整；③ 设置中心的信息架构有硬伤（AI 占位组、控件类型单一、与参考主题相比缺少"所见即所得"）**。

## 三、前端 UI 打磨问题（按组件逐项）

### 3.1 全局
- **字号体系断层**：正文 15px 起步、大量 11–12px 小字（角标/元信息），缺少 `--text-xs ~ --text-2xl` 阶梯令牌，小字号硬编码导致页面"碎"。
- **过渡时长不统一**：`a { transition: color .18s }`、导航 `.16s`、卡片 `.25s`——应统一为 `--dur-fast:160ms / --dur:200ms / --dur-slow:320ms` 三档令牌。
- **z-index 无刻度**：header、抽屉、灯箱、浮动目录、右键菜单各处手写 z-index，需建立 `10/20/30/40/50` 分层令牌。
- **`prefers-reduced-motion` 未全局处理**：仅个别动画可能照顾到；PJAX、光标跟随、入场动效都应尊重该媒体查询。
- **触控目标**：卡片角标点赞、评论区 `#` 锚点、页脚悬浮件实际点击区 < 40px，移动端难命中。

### 3.2 导航 / 头部
- 无滚动方向感知（下滚隐藏、上滚呼出），参考主题（Once/handsome）均支持；吸顶后建议加背景模糊（`backdrop-filter`）分层。
- 移动端抽屉导航：确认有遮罩锁定 body 滚动、Esc 关闭、焦点圈定（focus trap），这是参考主题普遍漏掉而 Ecod 可以做对的点。

### 3.3 卡片（9 种模式，最核心资产）
- 9 种卡片模式是亮点，但**模式间字号/间距/圆角不统一**：feature 与 default 的标题字号比例、gallery 三图的角标位置各不相同，显得"拼凑"。
- 图片无 `aspect-ratio` 占位 → 长列表图片加载时**布局跳动（CLS）**，这是设计上最伤"高级感"的一处，参考主题 Once 用骨架屏 + 固定比例解决。
- hover 反馈：阴影变化到位，但缺少图片 1.03 缩放等**内容层反馈**；同时要防布局位移（容器 overflow:hidden + transform）。
- 「新」角标硬编码 7 天（`functions.php:784`），建议进设置中心。

### 3.4 文章页
- 代码高亮 6 套主题可选但没有"跟随明暗模式"选项——浅色站选了深色高亮主题会突兀；建议默认 `auto`。
- 目录 TOC「浮动弹窗」设计有想法（与侧栏互斥），但缺少**当前章节高亮的滚动联动**确认与移动端折叠入口。
- TTS（tts.php）存在但入口位置/图标语义需复核。
- 版权块、打赏（参考主题标配）缺失——见功能矩阵。

### 3.5 评论区
- 等级徽章 7 档 + 博主标识完整，超出多数参考主题；但**输入区体验缺失项多**：无 Ctrl/Cmd+Enter 提交、无字数实时计数（后台有 EMaxLen 上限但前台不显示）、表情面板与输入框联动细节待查。
- 待审评论仅文案「等待审核」，建议加浅黄警示底 + 图标。

### 3.6 页脚 / 浮动件
- 返回顶部、进度条、主题切换三件并存时需检查**重叠与堆叠顺序**（右下角是拥挤高发区），参考主题统一收进一个"FAB 组"竖排，间距 12px、总高 ≤ 200px。

## 四、后台设置中心：现状 + 重设计

### 4.1 现状诊断

已做对的（保留）：侧边分组导航、分组描述文案、块系统拖拽排序、快照/导入导出、媒体库选图器。这两项（快照 + 块系统）**领先于全部参考主题**。

硬伤（要改）：

| # | 问题 | 参考主题做法 |
|---|---|---|
| 1 | 分组 12 个但**命名粒度不一**：「阅读」里混着 `EBirth`(站点数据)、「版式」里混着 `ELike`(点赞)/`ECtxMenu`(右键菜单)、「体验」是杂项筐 | Joe：8 组各管一类，属性单一归属 |
| 2 | **控件全部是 select on/off**：表单里 20+ 个「开启/关闭」下拉，既慢又不直观 | handsome/Puock：switch 开关 + radio 卡片 + 颜色选择器 + 数值滑块 |
| 3 | 主色是**文本框填 hex**，只靠 `data-ecod-color` 脚本补丁 | Once：原生 color picker + 预设色板一键选 |
| 4 | 改完设置**看不到前台效果**，要自己开新标签页 | handsome：设置卡片带迷你预览图；Joe：模式选择即所见卡片样式 |
| 5 | 「有未保存的修改」只有文案，无置底保存条、无离开拦截 | 参考：sticky 保存条 + beforeunload |
| 6 | 无分组内搜索；120+ 设置项靠翻 | Puock：设置页 Ctrl+F 兼容的高亮搜索 |

### 4.2 建议分组（12 → 9，一次归位）

| 分组 | 收编内容（从哪里来） |
|---|---|
| ① 站点 | 标识/Logo/Favicon/主色/副标题（现状保留）|
| ② 外观 | 深色模式（从"版式"迁入）、站点背景、入场动效、鼠标跟随（从"体验"迁入）、字体（从"代码"迁入）|
| ③ 首页 | Banner/标语（从"站点"迁入）+ 块系统 |
| ④ 版式 | 侧栏位置、卡片模式、缩略图位置、缩略图池、列表点赞 |
| ⑤ 侧栏 | 块系统（保留）|
| ⑥ 文章页 | 块系统 + TOC + 过期提醒（从"阅读"迁入）+ 高亮/高亮主题/灯箱（从"阅读"迁入）|
| ⑦ 互动 | 评论（审核规则）+ 列表点赞（从"版式"迁入）+ 阅读量（从"阅读"迁入）+ 邮件通知 |
| ⑧ SEO/性能 | sitemap、百度推送、CDN、懒加载（从"阅读/代码"迁入）、自定义 head/body |
| ⑨ 工具 | 快照/导入导出/特色页/robots（保留）|

删除：「AI 助手」占位组（P0-2）、「代码」组拆散归位、「体验」组拆散归位。

### 4.3 控件规范（后端注册类型扩展）

```
text        → 保留，但附占位提示
select(2项) → 一律改 Switch 开关（Typecho Radio + CSS 皮肤即可实现）
select(n项) → Radio 卡片：卡片模式、背景模式、高亮主题均带迷你示意图
color       → <input type="color"> + 6 个预设色板圆点
number      → 带 min/max 的滑块（摘要长度 60–300、导航上限、评论上限）
image       → 媒体库选图（已有，保留）
```

### 4.4 交互规范（设置中心 5 条铁律）

1. **保存**：置底 sticky 操作条（左：修改计数，右：保存主按钮）；保存中按钮 loading，成功 Toast，失败红色内联提示。
2. **离开拦截**：dirty 状态下切换分组/关闭页签需 `beforeunload`。
3. **即时预览**：主色、卡片模式、背景在设置面板顶部给 200px 高迷你预览区（纯 CSS 即可，不需 iframe）。
4. **危险操作**：恢复默认、删除快照需二次确认弹层，并说明影响范围。
5. **快捷键**：`Ctrl/⌘+S` 保存（阻止浏览器默认）。
