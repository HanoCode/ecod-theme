导出配置

把当前全部设置保存成 JSON 文件，换主题或重装后可原样恢复。模块布局的备份请用「模块管理台」右上角的导出。

导入配置

选择之前导出的 JSON 文件，设置项会被回填，确认无误后再点「保存设置」。

sitemap.xml

把站点全部文章、页面、分类、标签写成一个静态文件放到网站根目录。未开启伪静态时，PHP 路由无法接管 /sitemap.xml，用这里生成的文件最稳。

robots.txt

生成一份带 sitemap 地址的基础 robots.txt。根目录已有同名文件时不会覆盖，避免冲掉你自己的规则。

百度主动推送

把最近 20 篇文章地址推给百度，加快收录。Token 在「站长 → 收录与性能」里填，每天配额有限，不要反复点；24 小时内推过的文章会自动跳过。

自定义短链

把固定的推荐 / 活动链接变成 ?go=短码。正文里目标地址完全一致的链接会自动改用短码，访问走外链中转页并统计点击。

还没有自定义短链。填好目标地址后点「保存短链」创建第一份。

站内公告

给全部注册用户的站内消息发一条公告，出现在头部铃铛与个人中心「我的消息」。每人一条，不要频繁发送。

特色页

一键创建三个独立页面并自动选好模板，不用再手动建页、选「自定义模板」。已存在的不会重复创建。
